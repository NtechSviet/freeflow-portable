FreeFlow 1.2.0 - version portable (Windows x64)
===============================================

Aucune installation. Tout tient dans ce dossier, y compris votre profil, vos
reglages, votre dictionnaire/historique et le modele vocal.


CE QUE VOUS DEVEZ FAIRE (3 ETAPES)
----------------------------------
1) TELECHARGER  FreeFlow-Portable-1.2.0-win-x64.7z  (904 Mo) ici :
      https://github.com/NtechSviet/freeflow-portable/releases/latest
   (section "Assets" en bas de la version ; les liens "Source code" ne sont
   PAS l'application.)

2) EXTRAIRE l'archive avec 7-Zip (https://www.7-zip.org) :
      clic droit sur le fichier .7z
      > 7-Zip
      > Extraire vers "FreeFlow-Portable\"
   Choisir un dossier simple, par exemple :
      C:\Users\<vous>\Desktop\FreeFlow-Portable
   NE PAS extraire dans C:\Program Files (droits administrateur inutiles).
   Place necessaire : 2,1 Go pour l'archive + 6,4 Go une fois extrait, plus
   ~0,5 a 3 Go pour le modele vocal au premier demarrage.
   Sans 7-Zip, Windows refuse souvent d'ouvrir un .7z : c'est normal, ce n'est
   pas l'application qui est cassee.

3) DEMARRER : double-cliquez sur  "Lancer FreeFlow.cmd"  (dans le dossier
   extrait). Le fichier "FreeFlow Portable.lnk" n'est pas livre dans l'archive
   (il contient un chemin absolu) : pour avoir l'icone, double-cliquez une fois
   sur "Creer le raccourci.cmd" - il cree le raccourci ici meme.

   Windows peut afficher "Windows a protege votre ordinateur" (SmartScreen) :
   "Informations complementaires" puis "Executer quand meme". L'archive n'est
   pas signee, c'est l'avertissement standard.

   Au premier demarrage, FreeFlow telecharge le modele vocal large-v3
   (~3 Go avec une carte NVIDIA, ~0,5 Go en CPU) dans data\models : laisser
   finir, une progression s'affiche. Ensuite, tout fonctionne hors ligne.


LES RACCOURCIS
--------------
Ctrl + Alt + Espace  -> dicter (appuyer, parler, re-appuyer pour arreter)
Ctrl + Alt + H       -> panneau / hub (reglages, dictionnaire, historique)
Une icone apparait dans la zone de notification (pres de l'horloge).


VERIFIER QUE LE MODE PORTABLE EST ACTIF
---------------------------------------
Le mode portable est actif parce que le fichier "portable.txt" se trouve a
cote de FreeFlow.exe : le profil est ecrit dans .\data au lieu de
C:\Users\<vous>\AppData. Deplacez le dossier entier et tout suit.

Apres un premier lancement, vous devez voir :
      data\settings.json       vos reglages
      data\logs\freeflow.log   le journal
      data\models\             le modele telecharge
Si "data" n'apparait pas, c'est que FreeFlow n'a pas demarre : voir DEPANNAGE.


OU SONT MES DONNEES
-------------------
data\                     votre profil (reglages, dictionnaire, historique,
                          notes, reunions, caches) - deplacable avec le dossier
data\models\              le modele vocal large-v3 (~4,2 Go) : hors ligne
data\logs\freeflow.log    journal : demarrage, raccourcis, transcription,
                          collage, erreurs (mode developpeur)
data\settings.json        vos reglages (raccourcis, langue, etc.)
journal-demarrage.txt     cree par Diagnostic.cmd (sortie de demarrage)


DEPANNAGE
---------
- La dictee s'affiche dans la pastille mais le texte ne s'ecrit pas dans les
  autres applications (Word, Notepad, Chrome, Discord, applications Electron) :
  lancez "Reparer-Etiquettes.cmd", puis quittez et relancez FreeFlow.
  Explication : Windows interdit a un programme de simuler des frappes
  (Ctrl+V) vers une application "plus protegee" que lui. Si le dossier porte
  l'etiquette d'integrite "Niveau obligatoire faible", FreeFlow ne peut plus
  ecrire que dans les applications de meme niveau (barre de recherche Windows,
  certains utilitaires), ce qui donne exactement ce symptome. Le script remet
  l'etiquette "Niveau moyen" sur tout le dossier, ce qui retablit le collage
  partout. En cas de doute, verifiable en une ligne de commande :
      icacls "C:\...\FreeFlow-Portable"
  La derniere ligne doit indiquer "Niveau obligatoire moyen" (et non "faible").

- Rien ne se passe / fermeture immediate au demarrage :
  lancez "Diagnostic.cmd" : il ecrit journal-demarrage.txt (messages et code
  de sortie). Envoyez ce fichier avec data\logs\freeflow.log.
  Si le message parle du bac a sable (sandbox) de Chromium, demarrez avec
  l'option --no-sandbox en attendant :
      FreeFlow.exe --no-sandbox

- Windows demande un mot de passe administrateur : vous avez extrait le dossier
  dans C:\Program Files. Deplacez-le ailleurs.
- Port utilise : 48123 (moteur de transcription local, 127.0.0.1 uniquement).
- FreeFlow n'a pas besoin des droits administrateur. S'il est lance "en
  administrateur", il ne pourra plus ecrire dans les applications normales
  (Windows bloque les frappes d'un programme administrateur vers une fenetre
  non-administrateur) : lancez-le normalement.


ARRETER FREEFLOW POUR DE BON
----------------------------
Clic droit sur l'icone de la zone de notification > Quitter. Le moteur de
transcription (freeflow-stt.exe, ~700 Mo) s'arrete aussi : apres quelques
secondes il ne doit plus rester aucun processus FreeFlow ni freeflow-stt.
Cette version le garantit meme si la fenetre est tuee ou si l'application
plante (garde-fou de sortie).

S'il en reste quand meme (version precedente, arret brutal), en une commande :
    taskkill /IM FreeFlow.exe /T /F
    taskkill /IM freeflow-stt.exe /F

DESINSTALLER
------------
Fermez FreeFlow (icone de la zone de notification > Quitter), puis supprimez
ce dossier. Rien n'est ecrit ailleurs : ni registre, ni %APPDATA%, ni
demarrage automatique (sauf si vous l'avez active dans les reglages).
